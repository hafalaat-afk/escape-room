# The Crimson Key

An interactive Bahrain National Day science escape game created for the Nasser Centre for Science and Technology.

## Play locally

Open `index.html` in a modern desktop browser. No installation, internet connection, or build command is required.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload **the contents of this folder** to the repository root. `index.html` must remain at the top level.
3. Commit the files to the `main` branch.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.
7. GitHub will display the public game URL after deployment finishes.

## Included files

- `index.html` — complete game, styling, animations, puzzles, and JavaScript
- `assets/ncst-logo.png` — NCST logo
- `assets/bahrain-flag.webp` — Bahrain flag artwork
- `.nojekyll` — tells GitHub Pages to serve the static files directly

## Game controls

- Click objects and room areas to inspect them closely.
- Use the Hint button if needed.
- In the Chemistry room, collect the CO₂ canister and drag it from the inventory onto the fire.
- Enter the three discovered digits at the exit keypad.

## Facilitator codes

- Physics room: `427`
- Chemistry room: `389`

## Browser support

Use a current version of Chrome, Edge, Firefox, or Safari. A desktop or large tablet display is recommended for the station activity.
